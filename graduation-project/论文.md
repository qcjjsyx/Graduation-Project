# **基于多前沿方法的张量计算驱动型稀疏矩阵求解系统研究**

通过研究**多前沿稀疏矩阵 LU 分解算法**、**面向前沿矩阵矩阵的软硬件协同调度机制**以及**低精度整数化数据表示与数值实现方法**，实现**基于 GCU、HPU、ATU 和 SFU 的节点级前沿矩阵分解与更新加速系统**，达到在保证数值计算正确性的前提下提升稀疏直接求解过程的数据处理效率与硬件加速能力的目标
