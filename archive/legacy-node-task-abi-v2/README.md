# NodeTask / ABI v2 历史归档

本目录保存 Command v1 切换前的软件、SystemC 执行器和三代 optimization
实验代码，仅用于复查既有阶段性汇报，不属于当前构建与测试范围。

- `software/`：旧 pipeline、NodeTask、全局量化、地址规划和测试快照；
- `systemc/`：旧 artifact loader、system memory、NodeTask executor 和回归脚本；
- `optimizations/`：optimization-v1、tile-BFP v2 和 adaptive-precision v3。

当前主线不得从本目录导入代码或运行时数据。
