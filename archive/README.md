# 历史文档归档

这里保存具有实验、正式提交或设计决策追溯价值的材料。归档内容不再定义当前项目架构，也不应继续作为实现任务来源。

## 目录

- `formal/opening/`：开题和正式阶段材料；
- `history/code/`：早期代码说明和进度记录；
- `history/root/`：根目录问题记录；
- `history/experiments/`：历史行为模型实验报告；
- `history/design-notes/`：有参考价值的旧设计分析；
- `precision-history/`：旧定点稳定性实现报告；
- `optimization-v3/`：最新但已退出主线的全局 BFP 精度实验。
- `前期工作与重构依据：基线到v1-v3的演进说明.md`：前期工作量、问题发现和彻底重构依据。

`unused/optimization-v1/` 和 `unused/optimization-v2/` 保存更早的独立实验副本说明；它们与本目录中的历史材料一样，不属于当前主线。

当前架构以根目录 `docs/` 和 `项目总体架构重新定型方案.md` 为准。
