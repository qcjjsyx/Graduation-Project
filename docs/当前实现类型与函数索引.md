## 非主线辅助 Python 与测试类型

`sim/hardware.py` 的 HardwareConfig、AssemblySource、AssemblyStats、OperationLogEntry、LUResult、SolveResult、Quantizer、ATU、HPU、HardwareSystem 用于早期定点/全局指数实验；`sim/quant.py` 的 HardwareSimulatorQuantized、HardwareTRSMSolver 与 `sim/BLU_TRSM.py` 的 HardwareArray16x16 是数学原型；`hardware_experiment_report.py` 的 RunSummary 聚合历史实验。这些类不被当前 Command 编译器或 CMake 设备执行库调用，不能替代 T10 局部 INT32 或 T11 证据。

测试目录的 Harness、Test/Clock driver、ControlReference 一类对象负责 fixture、断言、时钟驱动、故障注入与独立控制序列预测；本轮按各测试目的概述，不列入上述生产类型计数。`third_party/nlohmann/json.hpp` 为第三方 JSON 解析库，不进行逐类型导读；archive/unused 仅用于确认旧 ABI 边界。
