# 基于张量计算的大型稀疏矩阵求解系统

## 📌 项目简介

本项目设计并实现一个面向大型稀疏非对称矩阵（Sparse Unsymmetric Matrices）的高性能求解系统。核心算法采用 **Multifrontal LU 分解** 与 **Supernode（超节点）** 技术，将稀疏分解转化为消去树上的稠密 front 计算，并通过张量计算单元（Tensor Core / Systolic Array）加速高吞吐矩阵更新。

系统采用软硬协同架构：

- **软件侧（Host）**：图/符号类预处理（重排、消去树、超节点、映射表）、任务生成与调度、精度控制（量化/缩放）、结果验证与迭代求精。
- **硬件侧（FPGA/加速器）**：front 的数值计算（分解 + 更新）、主元相关流水（搜索/交换）、以及高带宽写回与 Scatter-Add 装配。

核心目标是解决传统稀疏求解器在访存不连续、依赖链长、Pivot 稳定性与装配代价高等问题。

## 🚀 核心创新点

1. **异构计算架构**：分离标量瓶颈（SFU）与矩阵吞吐（Tensor Core），提升算力利用率。
2. **零拷贝主元交换（ATU）**：以“逻辑行号→物理地址”间接寻址替代真实搬运，降低 Pivot 代价。
3. **前瞻流水线（Lookahead + Scoreboard）**：在超节点内部以记分牌管理依赖，掩盖主元搜索与标量运算延迟。
4. **隐式装配（Scatter Engine + Relative Map）**：以映射表驱动子节点对父节点的 Scatter-Add，降低 Extend-Add 的索引与访存开销。

## ❔待解决问题（将作为论文/答辩的“风险与对策”条目）

1. **精度与数据类型**：当前计算核心仅支持 32-bit 整数通路时，如何支持负数与获得接近 FP16 的效果？建议路线：共享指数（front/panel 级）量化 + 迭代求精；同时硬件需具备“补码有符号乘加语义”。
2. **SFU 的实现边界**：由CPU软核来接管，我们只需给出对应的RV指令
3. **验证形式**：需要给出与参考求解器（如 CPU 稀疏 LU）一致的误差指标：残差范数、后向误差、收敛步数、以及性能（端到端时间、带宽占用）。
4. **Benchmark 例子**：至少包含（a）可控小规模矩阵用于功能与边界条件；（b）中等规模稀疏矩阵用于端到端演示；（c）含 Pivot 的非对称矩阵用于稳定性展示。
