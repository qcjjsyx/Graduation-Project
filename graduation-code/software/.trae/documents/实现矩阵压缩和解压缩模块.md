# 矩阵压缩和解压缩模块实现计划

## 目标

创建 `matrix_compress` 文件夹，包含以下文件：

* `compress.py` - 负责将稀疏矩阵压缩为COO、CSR或BSCR格式

* `decompress.py` - 负责将压缩格式解压缩回原始矩阵

## 功能设计

### 1. 压缩功能 (`compress.py`)

* **支持格式**：COO、CSR、BSCR

* **输入**：Matlab格式(.mat)的稀疏矩阵

* **输出**：压缩后的二进制文件

* **核心功能**：

  * 读取.mat文件中的稀疏矩阵

  * 转换为指定的压缩格式

  * 保存压缩数据到二进制文件

  * 生成压缩统计信息

### 2. 解压缩功能 (`decompress.py`)

* **支持格式**：COO、CSR、BSCR

* **输入**：压缩的二进制文件

* **输出**：恢复的稀疏矩阵（scipy.sparse格式）

* **核心功能**：

  * 读取压缩文件

  * 解析压缩格式

  * 恢复为原始稀疏矩阵

  * 验证解压缩结果

### 3. 压缩格式实现细节

#### COO格式

* 存储：行索引、列索引、值的三元组

* 优势：格式简单，易于实现

#### CSR格式

* 存储：行指针、列索引、值

* 优势：访问效率高，内存占用小

#### BSCR格式

* 存储：块行指针、块列索引、块值

* 优势：对于分块矩阵，压缩率更高

## 技术实现

1. **依赖库**：

   * numpy - 数值计算

   * scipy - 稀疏矩阵操作

   * scipy.io - 读取.mat文件

2. **文件结构**：

   ```
   matrix_compress/
   ├── __init__.py
   ├── compress.py
   └── decompress.py
   ```

3. **接口设计**：

   * `compress.py`:

     * `compress_matrix(matrix, format, output_path)` - 压缩矩阵

     * `read_mat_file(file_path)` - 读取.mat文件

   * `decompress.py`:

     * `decompress_matrix(input_path, format)` - 解压缩矩阵

     * `validate_compression(original, decompressed)` - 验证压缩/解压缩结果

4. **性能考虑**：

   * 处理大型稀疏矩阵时的内存使用优化

   * 压缩和解压缩的时间效率

   * 支持大型矩阵的分块处理

## 实现步骤
